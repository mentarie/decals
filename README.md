# decals

DE calculator: Data Engineering Knowledge Base (Decision Wizard, Tool Explorer, Spark & Storage sizing calculator, catatan referensi).

Live: https://mentarie.github.io/decals/

## Struktur

- `index.html` — seluruh aplikasi dalam satu file (HTML + CSS + JS, tanpa library eksternal).
- Semua konten ada di objek `KB_DATA` di bagian atas `<script>`. Cari komentar `// TAMBAH TOPIK BARU DI SINI` untuk menambah topik.

## Update

1. Edit `index.html` (biasanya hanya bagian `KB_DATA`).
2. `git add index.html && git commit -m "Update KB" && git push`
3. GitHub Pages memperbarui situs otomatis dalam 1–2 menit.
